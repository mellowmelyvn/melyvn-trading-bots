# MELYVN TRADING BOTS

A futuristic, responsive landing page for MELYVN TRADING BOTS, showcasing automated trading tools, EA setup support, and managed-account service enquiries.

## Website features

- Responsive dark interface with animated market-style chart and subtle motion effects.
- Trading bot cards, including the Gold Scalping EA (starting price shown as $30).
- Managed-account enquiry section explaining discovery, risk review, permissions, and reporting.
- Contact enquiry form that opens the visitor's email application.
- Risk disclosures and reminders not to share account passwords or one-time codes.

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save**. GitHub will provide the published website address after deployment.

## Before publishing

Edit `index.html` and replace these placeholders in the contact section and form handler:

- `YOUR-BUSINESS-EMAIL`
- `ADD-YOUR-WHATSAPP-LINK`

Only publish contact details that you want customers to see.

## Important limitations

This is a static front-end website. It does **not** currently provide:

- Real customer accounts, authentication, or a private client dashboard.
- Live broker connectivity, account monitoring, or trade execution.
- Deposit/withdrawal processing or custody of customer funds.
- Secure storage or processing of customer information.

The sample trading interface is illustrative only. Do not enter or collect broker passwords, one-time codes, API secrets, or wallet recovery phrases through this site.
